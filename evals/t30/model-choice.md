# T30. Модель для чата покупателей Softline

**Условие команды на 27 ноября 2026 года — 0 ₽ дополнительных платежей за модель.** Сначала проверили, можно ли обслуживать покупателей из уже оплаченной подписки OpenCode Go. Подходящая по размеру открытая модель там есть. Доступ к ней из публичного виджета по подписке подтвердить пока не удалось. Рабочий кандидат для испытания на собственном железе — Qwen3.5-9B, запасной для меньшего объёма свободной VRAM — Qwen3.5-4B. Выбор для публичного стенда остаётся открытым до подтверждения доступного хоста или поддерживаемого бесплатного API.

## Что именно даёт OpenCode Go

У Go есть HTTP API, им могут пользоваться и сторонние кодинг-агенты. Для генерации текста документация описывает типичный трафик кодинг-агента, собственную идентификацию клиента и сессию. Явное исключение для произвольных приложений касается эмбеддингов и специализированных вызовов принятия решений. Они могут помочь с поиском или классификацией, но для ответа покупателю нужен генеративный чат. Для моделей бесплатного чат-тарифа OpenCode отдельно указывает, что за пределами OpenCode клиент получит HTTP 403. Поддержку публичного виджета как клиента подписки провайдер не описывает. Запрос из нашего бэкенда с ключом мы не выполняли. [Документация Go](https://opencode.ai/docs/console/go/) · [Сторонние клиенты и бесплатные модели](https://opencode.ai/docs/console/harnesses/)

Организатор разрешил иностранный API при условии, что саму модель можно развернуть в контуре заказчика. Для соответствия нужны открытые веса, лицензия с локальным использованием и дообучением и веса до 128 ГБ VRAM при Q4 или выше. [Условия](https://t.me/c/6002613004/115) · [Уточнение о контуре](https://t.me/c/6002613004/133)

- **Tencent Hy4-flash** есть в каталоге Go как `hy4-flash-free`. Tencent публикует исходные веса, лицензия разрешает производные модели, включая дообучение. Для текстового чата у сборщика Xylolabs есть IQ4_XS / IQ4_NL на **122,6 ГБ**. Это размер файлов весов. Рабочая память движка и контекста идёт сверх этой суммы. Документированный пример сборщика выносит таблицу Engram в RAM. Доступность именно этой модели внешнему чату покупателей по Go остаётся неподтверждённой. [Каталог Go](https://opencode.ai/inference/go/v1/models) · [Модель](https://huggingface.co/tencent/Hy4-flash) · [Лицензия, пп. 2 и 10](https://huggingface.co/tencent/Hy4-flash/blob/main/LICENSE) · [Размер и локальный запуск](https://huggingface.co/Xylolabs/Hy4-flash-GGUF/blob/5b314cd34f7b1e08de2c2d2229811c90636d1c8a/README.md)
- **GLM-5.3-Flash** тоже входит в Go и имеет открытые веса. У неё 320 млрд параметров. Уже при ровно 4 битах на параметр веса занимают около **160 ГБ** до служебных данных. Эта модель не проходит ограничение по памяти. У Go также есть `qwen3.8-flash`, но отдельные веса для `Qwen3.8-27B` или `Qwen3.8-Flash-Next` сами по себе не доказывают совпадение версии с этим API. [GLM-5.3-Flash](https://huggingface.co/zai-org/GLM-5.3-Flash) · [Каталог Go](https://opencode.ai/inference/go/v1/models)

На машине разработки доступна RTX 3080 Ti с 12 ГиБ VRAM. Это возможный хост для прогона, его доступность в течение всего периода оценки команда пока не подтверждала. Качество на русском, пиковую память и время до полезного ответа пока не измеряли.

В T32 проверяем первый сквозной запрос через `llm_call`: вопрос о лицензии, вызов каталога, результат инструмента, короткий ответ с источником. Для T34 нужны одни и те же открытые диалоги со сменой SKU и обязательной передачей менеджеру. В T19 отдельно отражаем нулевую плату за токены у локального движка и фактические затраты на работу хоста.
