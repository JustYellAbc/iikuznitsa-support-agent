# Т23 · Как покупатель выбирает лицензию в чате Softline

**Один дубль, план 2:50, запас 10 секунд.** Михаил записывает экран и голос одновременно. Жюри должно увидеть три результата: после изменения запроса меняется товар, ответ оператора помогает следующему покупателю, а сумма в документе совпадает с последней версией КП.

Конкурсный предел — 3:00. Экран записываем непрерывно, включая переключения окон и открытие PDF. Правила разрешают ускорить только ожидание ответа модели. Для нашего дубля планируем обычную скорость. [Положение, п. 4.5(1)](https://xn--80ancabkw0c4a.xn--p1ai/regulations/v1.html)

## Перед записью на Т22

Разложить окна по порядку: **А** — новый чат покупателя, **М** — кабинет уже вошедшего менеджера, **Б** — новый покупатель в отдельной сессии, **В** — чистый чат для подбора по потребности, **Г** — отдельный чат с подготовленной закупкой. Записывать весь экран, чтобы переключения были видны. Окна подписать для себя до старта. Реплики ниже можно вставлять из буфера.

В **Г** подготовить только исходное состояние: черновик MDaemon Server и Connector for Outlook на 20 мест, по одной упаковке каждого (SKU 19576 и 359841), тестовые реквизиты и согласованные условия. Включить открытие скачанного PDF в браузере. Пересчёт на 40 мест, согласие покупателя и выдачу счёта показать в кадре. Перед публикацией FAQ убедиться, что в базе не осталась наша статья с репетиции.
