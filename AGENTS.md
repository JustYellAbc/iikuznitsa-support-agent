# Правила изоляции данных и закрытой выборки (Eval)

- Запрещено читать, индексировать, копировать или использовать при разработке промптов и кода содержимое `data/private/**` и внешней директории закрытой контрольной выборки (`EVAL_HOLDOUT_DIR`, по умолчанию вне папки репозитория).
- Сырые переписки из `data/raw/чаты поддержки.zip` содержат неполностью обезличенные ПДн — запрещено коммитить их в публичный репозиторий и отправлять внешним LLM-провайдерам без предварительного маскирования (`eval/run_eval.py` автоматически применяет `scrub_pii` перед отправкой holdout-сообщений).
- Для воспроизводимой генерации закрытой выборки проверяющий задаёт собственный `EVAL_SPLIT_SEED` и внешний `EVAL_HOLDOUT_DIR` через переменные окружения.
