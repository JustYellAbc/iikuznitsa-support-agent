# T30. Модель для чата покупателей Softline

**Условие команды на 27 ноября 2026 года — 0 ₽ дополнительных платежей за модель.** Сначала проверили, можно ли обслуживать покупателей из уже оплаченной подписки OpenCode Go. Подходящая по размеру открытая модель там есть. Стандартные условия подписки рассчитаны на внутреннее использование. Для доступа через публичный виджет потребовались бы специальные условия OpenCode. Рабочий кандидат для испытания на собственном железе — Qwen3.5-9B, запасной для меньшего объёма свободной VRAM — Qwen3.5-4B. Выбор для публичного стенда остаётся открытым до подтверждения доступного хоста или поддерживаемого бесплатного API.

## Что именно даёт OpenCode Go

У Go есть HTTP API, им могут пользоваться и сторонние кодинг-агенты. Для генерации текста документация описывает типичный трафик кодинг-агента, собственную идентификацию клиента и сессию. Явное исключение для произвольных приложений касается эмбеддингов и специализированных вызовов принятия решений. Они могут помочь с поиском или классификацией, но для ответа покупателю нужен генеративный чат. Для моделей бесплатного чат-тарифа OpenCode отдельно указывает, что за пределами OpenCode клиент получит HTTP 403. Это ограничение бесплатного тарифа не доказывает отказ для подписочного Qwen. Более существенное ограничение указано в Terms of Use от 25 ноября: сервис предоставляется для собственного внутреннего использования. Предоставление сервиса или ключа третьим лицам требует письменного одобрения OpenCode. Когда покупатели и жюри сами отправляют сообщения в публичный чат, их запросы обслуживает наша подписка. Ключ на сервере сохраняет секретность, но не меняет аудиторию. Подтверждения специальных условий для нашего стенда у команды нет. [Условия сервиса](https://opencode.ai/legal/terms-of-service) [Документация Go](https://opencode.ai/docs/console/go/) · [Сторонние клиенты и бесплатные модели](https://opencode.ai/docs/console/harnesses/)

**К сдаче допускается решение на закрытой облачной модели.** Команда отдельно спросила, достаточно ли для оценки пути внедрения показать на стенде работу на модели с открытыми весами и замер качества именно на ней. Организатор подтвердил оба пункта. Для этой модели ориентируемся на локальный запуск и дообучение по лицензии и веса в пределах 128 ГБ VRAM при Q4 или выше. Один открытый движок может обслуживать и покупателей на демо, и проверочные диалоги. Два провайдера для сдачи не требуются. [Вопрос команды](https://t.me/c/6002613004/134) · [Ответ организатора](https://t.me/c/6002613004/135) · [Условия для весов](https://t.me/c/6002613004/115)

- **Tencent Hy4-flash** есть в каталоге Go как `hy4-flash-free`. Tencent публикует исходные веса, лицензия разрешает производные модели, включая дообучение. Для текстового чата у сборщика Xylolabs есть IQ4_XS / IQ4_NL на **122,6 ГБ**. Это размер файлов весов. Рабочая память движка и контекста идёт сверх этой суммы. Документированный пример сборщика выносит таблицу Engram в RAM. Доступность именно этой модели внешнему чату покупателей по Go остаётся неподтверждённой. [Каталог Go](https://opencode.ai/inference/go/v1/models) · [Модель](https://huggingface.co/tencent/Hy4-flash) · [Лицензия, пп. 2 и 10](https://huggingface.co/tencent/Hy4-flash/blob/main/LICENSE) · [Размер и локальный запуск](https://huggingface.co/Xylolabs/Hy4-flash-GGUF/blob/5b314cd34f7b1e08de2c2d2229811c90636d1c8a/README.md)
- **GLM-5.3-Flash** тоже входит в Go и имеет открытые веса. У неё 320 млрд параметров. Уже при ровно 4 битах на параметр веса занимают около **160 ГБ** до служебных данных. Эта модель не проходит ограничение по памяти. У Go также есть `qwen3.8-flash`, но отдельные веса для `Qwen3.8-27B` или `Qwen3.8-Flash-Next` сами по себе не доказывают совпадение версии с этим API. [GLM-5.3-Flash](https://huggingface.co/zai-org/GLM-5.3-Flash) · [Каталог Go](https://opencode.ai/inference/go/v1/models)

На машине разработки доступна RTX 3080 Ti с 12 ГиБ VRAM. Это возможный хост для прогона, его доступность в течение всего периода оценки команда пока не подтверждала. Качество на русском, пиковую память и время до полезного ответа пока не измеряли.

В T32 проверяем первый сквозной запрос через `llm_call`: вопрос о лицензии, вызов каталога, результат инструмента, короткий ответ с источником. В T34 запускаем открытый движок через тот же чат стенда, сохраняем его идентификатор в трассе и измеряем правильность SKU и обязательных передач на фиксированных диалогах. В T19 сдаём расчёт стоимости и при бесплатной модели: указываем 0 ₽ за токены и отдельно учитываем фактические затраты на хост. [Ответ о расчёте](https://t.me/c/3921430443/765)
