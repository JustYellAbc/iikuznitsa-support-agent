# Т09 · Клиентский чат

Виджет открывается кнопкой «Чат с поддержкой» на демонстрационной странице товара по адресу `/chat/`. Каталог и ссылки в шапке ведут в магазин Softline. Для обслуживания достаточно отдать содержимое `frontend/` как статические файлы и проксировать `/api/v1/` на реализацию Т04 того же origin. Сборка JavaScript и внешние библиотеки не нужны.

## Локальная проверка

Из корня репозитория запустите `python frontend/preview.py` (Python 3.11+), затем откройте [локальный чат](http://127.0.0.1:8099/chat/). Другой порт задаётся через `--port`. Предпросмотр слушает loopback и воспроизводит события покупателей из `contracts/t04/examples.json`. Память предпросмотра очищается при перезапуске. Для отдельного диалога откройте адрес в новой независимой вкладке.

- **Подбор и тендер.** Отправьте по очереди «Нужен Мдеймон для 20 человек. Покупатель — юрлицо.», «Покупаем впервые.», «Это тендер. Нужны документы.». Появятся уточнение, карточка с ценой и источником, подтверждение передачи и вопрос оператора. Затем отправьте «Уточнил у закупок: для этого этапа нужна только ссылка на выбранную лицензию.». Ответ оператора и закрытие останутся в этой истории.
- **Оператор с первого сообщения.** В новом диалоге сразу нажмите «Позвать оператора».
- **Состояния цены.** В новом диалоге отправьте «Сверьте цену BookOffice, Iceni Infix Server и Adobe InCopy CC. Каков срок BookOffice?». Проверьте карточки, включая неизвестный срок и цену по запросу.

Для локального воспроизведения важен точный текст реплик. На общем стенде ввод обрабатывает сервер. Клиент использует создание диалога, команды и чтение событий Т04. Отправка текста оператору включает `handoffId`. История восстанавливается с `after=0`, а ключ незавершённой отправки хранится в `sessionStorage` вкладки для повтора. Демонстрационный сервер не развёртывается как API стенда.
