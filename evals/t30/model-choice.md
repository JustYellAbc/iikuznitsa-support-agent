**Выбор на 27 ноября 2026 года — Qwen3.6-35B-A3B через Yandex AI Studio, синхронный API с оплатой за токены.** В одном ходе агенту нужно понять запрос на русском, вызвать наш поиск и дать короткий ответ по результату. У этой версии есть открытые веса, вызов пользовательских функций и режим с отключаемым рассуждением. Провайдер документирует Chat Completions и выставляет цену в рублях. Для первого выпуска используем одну модель для обоих профилей. Скорость и правильность выбора товара проверяет T34. ## Можно ли использовать подписку OpenCode Go

Для разработки команды — да. Для обслуживания покупателей выбираем прикладной API. В условиях Go указан обычный трафик кодинг-агентов, идентификация клиента и идентификатор сессии. Наличие HTTP-эндпоинта само по себе не распространяет подписку на публичный чат магазина. В списке Go на дату проверки также отсутствуют точные идентификаторы трёх выбранных моделей. Для резерва есть **та же Qwen3.6-35B-A3B** у DeepInfra за **$0,10 / $0,95** за миллион входных / выходных токенов. Её можно подключить через существующий Bearer-клиент и тот же набор инструментов. [Условия Go](https://opencode.ai/console/go) · [Список моделей Go](https://opencode.ai/zen/go/v1/models) · [Резервный API](https://deepinfra.com/Qwen/Qwen3.6-35B-A3B/api)

## Что передаём в T32 и T34

- **Подключение в T32.** Через `app.core.llm.llm_call` отправлять запросы на `https://ai.api.cloud.yandex.net/v1/chat/completions`. Для сервисного аккаунта нужны роль `ai.languageModels.user`, ключ со scope `yc.ai.foundationModels.execute` и ID каталога. Документированный HTTP-пример передаёт `Authorization: Api-Key …` и `OpenAI-Project: <folder_id>`. Текущая обёртка формирует только Bearer-заголовок. В T32 добавить поддержку заголовков Яндекса, сохранив существующий режим Bearer. Ключ остаётся на сервере. Первый запрос с ключом — синтетический поиск товара, возврат результата инструмента и ответ покупателю. [Пример запроса провайдера](https://aistudio.yandex.ru/ru/docs/ai-studio/operations/generation/multimodels-request)
- **Что показать на стенде.** Для короткого ответа начать с отключённого рассуждения. Цена и SKU приходят из инструмента, расчёт и выпуск документа остаются у коммерческого сервиса. В трассе должны быть модель, инструмент, версия источника, токены и время. Для внешнего API передавать только необходимые обезличенные данные. История и реквизиты организации для документа остаются на сервере.
- **Экономика для T19.** Условные 2 000 входных и 200 выходных токенов суммарно за все вызовы одного обращения обойдутся в **0,46 ₽** на основном тарифе без кеша. Повторная отправка истории и результата нашего инструмента входит в оплачиваемый вход. Льготная ставка Яндекса для токенов встроенных инструментов на наши функции не распространяется. В расчёт T19 брать фактический расход по диалогу и ставки RUB. Для дневного лимита текущей обёртки, которая читает USD, в T32 согласовать пересчёт с тем же курсом. [Правила тарификации](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing)
- **Проверка в T34.** Прогнать одинаковые открытые диалоги на одном снимке каталога. Штатная покупка проверяет выбор SKU, смена 20 мест на 37 — сброс устаревшей лицензии, запрос тендерных документов — обязательную передачу своему менеджеру. Записать долю верных SKU и передач, ошибки с ценой, p50/p95 до первого полезного ответа и стоимость корректно завершённого обращения. Решение о смене модели принимаем по этим результатам.

Для T30 сверены карточки авторов, лицензии, размеры весов, каталог и тарифы провайдеров. Авторизованные вызовы с командного стенда, качество ответов на русском и фактическая задержка остаются проверками T32 и T34.
