# T30. Выбор модели для демо Softline

**27 ноября 2026 года команда выбрала `qwen3.8-flash` через OpenCode Go.** Две модели Qwen прошли все семь открытых сценариев в обоих прогонах. У Flash покупатель быстрее получал ответ. Провайдер даёт доступ к модели и вызовам инструментов через OpenAI-совместимый API. Профиль демостенда включает `AGENT_ENGINE=tools`, отключает мок и задаёт Flash для обоих профилей модели. Шаг `Start demo Qwen backend` успешно выполнен. Все три модели проверили через один интерфейс Go на одной сборке и снимке каталога. Семь сценариев охватывали цену по SKU, сброс пароля, запрос цены у менеджера, подбор лицензии, изменение числа мест, передачу тендера и ответ из опубликованной статьи. Время считали от действия покупателя до видимого сообщения по 12 ходам с вызовом модели на каждого кандидата. Два тендерных хода у каждого кандидата обработал сервер, они учитываются в результате сценариев. У Hy4 во втором круге подбор исчерпал лимит вывода, а два последующих шага зависели от выбранного SKU. ## Вариант для контура заказчика

Организаторы разрешили облачную модель на демо. Для оценки внедрения нужен показ и замер качества на открытых весах с возможностью локального запуска и дообучения. Ориентир по памяти из требований организаторов — 128 ГБ VRAM при Q4 или выше.

| Модель | Что известно о локальном запуске |
|---|---|
| Qwen3.8-Flash | Alibaba связывает своё API-имя с **Qwen3.8-Flash-Next**. Точная ревизия развёртывания в Go не раскрыта. Qwen Community License 1.0 допускает запуск и дообучение на своих условиях, включая отдельные условия коммерческого использования в п. 2. Четыре файла сборки Unsloth `UD-Q4_K_XL` вместе занимают **111,33 ГБ**. [Сообщение Alibaba](https://www.alibabacloud.com/blog/qwen3-8-flash-next-a-new-architecture-towardsultimate-cost-efficiency_603501) · [Веса](https://huggingface.co/Qwen/Qwen3.8-Flash-Next) · [Лицензия](https://huggingface.co/Qwen/Qwen3.8-Flash-Next/blob/main/LICENSE) · [Файлы выбранного кванта](https://huggingface.co/unsloth/Qwen3.8-Flash-Next-GGUF/tree/f5d175de2cf7f720d45d6064019a81fcf056e986/UD-Q4_K_XL) |
| Qwen3.7-Plus | Резерв для облачного демо. Для точного API-варианта команда не подтвердила публичные веса, лицензию на дообучение и размер Q4. Вариант для своего контура по нему не заявляем. [Каталог API Go](https://opencode.ai/inference/go/v1/models) |
| Hy4-flash | Tencent публикует веса по Tencent Hy License, включая условия для производных моделей и дообучения. У Xylolabs файлы IQ4_XS занимают около 122,6 ГБ. Для нашего агента перевесил результат второго круга. [Веса Tencent](https://huggingface.co/tencent/Hy4-flash) · [Лицензия](https://huggingface.co/tencent/Hy4-flash/blob/main/LICENSE) · [Квант и конфигурация](https://huggingface.co/Xylolabs/Hy4-flash-GGUF) |

**Замер на собственном сервере (T36).** Для варианта в контуре заказчика фиксируются ревизия Flash-Next, квант, движок, длина контекста и параллелизм. Измеряются пиковые VRAM и RAM при загрузке и генерации и выгрузка на CPU. На той же открытой выборке записываются ответы и вызовы инструментов локальной модели. По этим измерениям проверяется ориентир 128 ГБ и рассчитывается стоимость собственного сервера.

## Стоимость сдаваемой сборки

На время конкурсного демо стенд подключён к облачному API-провайдеру модели `qwen3.8-flash` через OpenAI-совместимый интерфейс. Подключение задаётся конфигурацией (`LLM_BASE_URL`, `LLM_API_KEY`, `MODEL_*`). Поэтому тот же код без изменений работает с провайдером с потокенной оплатой (pay-as-you-go), с российским провайдером с OpenAI-совместимым API или с открытыми весами линейки Qwen под vLLM в закрытом контуре заказчика. Финальный расчёт T19 ведётся по чистому API pay-as-you-go, без абонентской платы. Учитываются фактические вызовы и повторы сдаваемой сборки по ставкам 0,15 и 0,47 USD за миллион входных и выходных токенов, пересчитанным по курсу ЦБ из шаблона организаторов, и облачная VM стенда Selectel за 113,60 ₽/сут без НДС. Для собственного сервера в расчёт войдёт стоимость машины при измеренной нагрузке.
