# Т31. Инструменты поиска для агента

Сервер передаёт путь к индексу из настроек. Модель передаёт только запрос, артикул или параметры поиска. Инструменты из `catalog.tools` читают данные локально и не вызывают LLM.

| Вызов из Python | Что получает агент |
|---|---|
| `search_catalog(index, "MDaemon Standard на 20 мест", license_type="Полная версия")` | До трёх кандидатов с названием, offerId, типом и размером лицензии. Алиас помогает найти семейство. Эквивалентность редакций требует отдельного источника. |
| `search_catalog(index, "Нужен редактор PDF", by_need=True, limit=2)` | Кандидаты для дальнейшей проверки по карточкам. Совместимость, бюджет и единицу лицензирования сверяем отдельно. |
| `get_offer(index, "48093")` | Текущая карточка строго по offerId. Цена за упаковку в копейках, наличие из фида, оговорка для покупателя, срок и параметры карточки. |
| `search_store_knowledge(index, "Оплата банковским платежом")` | Заголовок, текст, URL статьи магазина и SHA-256 текста. Поиск по словам может вернуть смежную статью. Перед ответом проверяем сам текст. |
| `await search_published_knowledge("Где настроить уведомления в Softline Store?")` | Точный опубликованный ответ менеджера или одобренная формулировка. Версия — ID публикации. Отзыв удаляет статью из поиска. |

При успехе `ToolResult.data` — список. Каждая запись несёт свою ссылку `source` и версию `version`. Для товара версия — дата снимка фида. Верхний `source_ref` указывает на первый результат. Для ответа о втором товаре берём ссылку из его записи. Ничего не найдено — `ok=true, data=[], source_ref=null`. Неисправный индекс даёт `ok=false, error="catalog_unavailable"`, конфликт опубликованных ответов — `conflicting_publications`. Оба исхода требуют уточнения или передачи менеджеру. Поисковый запрос ограничен 500 символами, выдача — от одной до пяти записей.

Три контрольные позиции магазина — 61557 с опубликованной ценой и наличием, 48093 с ценой и неподтверждённой поставкой, 504 с ценой по запросу. Отсутствующее значение передаётся как `null`. По уточнению Softline положительная цена при `available=false` позволяет выдать КП и счёт. Фактическую поставку подтверждает менеджер. Выдача документа — действие коммерческого сервиса.

Из корня репозитория с зависимостями backend выполните `python -m pytest -q catalog/test_tools.py catalog/test_search.py`. Чтобы включить сверку с реальным магазином, задайте `T31_CATALOG_INDEX` равным абсолютному пути к снимку Т06 от 25 ноября. Остальные проверки создают временный каталог и отдельную базу публикаций.
